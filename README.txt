SMART WAREHOUSE MANAGEMENT SYSTEM — HTML/CSS/JS EDITION

Files:
- index.html: application shell
- styles.css: styling adapted from the original project stylesheet
- app.js: client-side demo navigation, tables, add/edit/delete, search, CSV export

Run:
1. Extract the ZIP.
2. Open index.html in a browser, or use VS Code Live Server.
3. No npm install or build step is required.

Deployment:
- GitHub: upload the files in this folder (not only the ZIP).
- Vercel: Framework Preset = Other; Build Command = blank; Output Directory = . (root).

Important:
This is a frontend-only conversion. Data is demo data stored in browser localStorage; MongoDB, Express APIs, server-side authentication, and multi-user sync are not included. Some operational screens use generic records rather than the original backend-connected workflows. The visual theme and navigation follow the supplied project's CSS and sidebar.
